# TradeWise — Frontend

React 19 + Vite single-page application for the TradeWise paper-trading platform.

> 📖 Full project documentation, API reference, setup and architecture are in the **[root README](../Readme.md)**.

## Quick start

```bash
npm install
echo "VITE_API_URI=http://localhost:5000" > .env
npm run dev          # http://localhost:5173
npm run build        # production build
npm run lint         # ESLint
```
